# ResearchMind AI Frontend

The frontend of ResearchMind AI is built using React and Vite. It provides a modern dashboard interface for interacting with the ResearchMind AI backend services.

---

## Technology Stack

* React
* Vite
* Tailwind CSS
* React Router
* Axios
* React Icons
* Recharts
* Framer Motion

## Installation

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
